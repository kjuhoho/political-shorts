# 롱폼 운영 기억 / 필수 작업 규칙

- 소유 범위는 `longform_system/` 및 독립 롱폼 workflow뿐이다. 숏폼 코드·설정·다른 작업자의 변경은 수정하거나 커밋하지 않는다.
- 사용자는 추가 비용을 금지했다. 유료 대체 API, 크레딧 구매·리셋은 별도 명시 승인 없이 사용하지 않는다.
- 점검은 기존 로그·산출물부터 읽고 로컬 mock 테스트를 우선한다. 점검만을 위해 실제 생성·렌더·게시 workflow를 실행하지 않는다.
- 같은 실패를 원인 수정 없이 반복 실행하지 않는다. 실패 지점부터 재개하고 동일 입력·모델·설정의 완료 응답은 캐시를 재사용한다. 입력이나 검수 지침이 바뀌면 캐시 키도 달라져야 한다.
- 스케줄은 하루 한 번만 LLM 제작에 진입한다. 이후 시간대는 제작 전 준비 실패에 한해서 재시도한다. 품질·쿼터 실패는 자동 전체 재생성하지 않는다.
- 호출 전 출력 여유까지 예산을 확인한다. 실패·타임아웃도 usage.json에 남기며 사용량이 불명확하면 소비하지 않았다고 가정하지 않는다.
- 사용자에게 실제 청구액, Groq 토큰, Codex 계정 한도를 혼동해서 설명하지 않는다. 계정 한도를 해당 스레드 비용으로 단정하지 않는다.
- 진행 상태가 변하지 않았을 때 긴 로그를 반복 조회하거나 동일한 설명을 반복하지 않는다. 제품의 완료 대기 기능과 짧은 상태 확인을 사용한다.
- 자동 95점은 사실의 증명이 아니다. 출처·날짜·기관명·추정과 사실을 확인한다. 절약을 위해 품질/안전 검수나 중복 방지 장치를 제거하지 않는다.
- 기본 약 5분·차분한 음성을 우선한다. 741어절이 7분 33초였으므로 750~850어절 요구를 다시 강제하지 않는다. 현재 460~560어절, 실제 240~360초 검증을 사용한다.
- 게시 기록이나 불명확한 업로드 예약이 있으면 재업로드하지 않는다. 기존 영상 ID부터 확인한다.

재사용 캐시와 실패 시 사용량 기록은 이 점검 이후 도입했으며 과거 실행에는 없었다.

## 2026-09-29 재발 방지

- 9/26·9/27 실패는 근거 인용이 유효하지 않은 검수 응답, 9/27 후속 실행은 Groq 연결 끊김이었다. 업로드 API 문제로 오진하지 않는다.
- 연결 장애는 실행 전체에서 딱 한 번, 실패한 LLM 요청만 같은 예산 안에서 재시도한다. 이전 요청의 불명확한 소비 예약량은 유지한다. 429/품질 실패는 이 재시도 대상이 아니다.
- 잘못된 검수 응답과 필드별 실패 이유를 artifact에 보존하고, 수정 호출에 구체적인 인용 오류를 전달한다. 근거 조건이나 95점 기준은 완화하지 않는다.
- GitHub의 success는 건너뛰기일 수도 있다. published.json/업로드 영수증과 실제 영상 주소를 확인한다.
- GitHub schedule은 PC/Codex와 독립적이지만 정시 시작·매일 성공을 보장하지 않는다. 9/28 실행은 예약 시각보다 늦게 시작했으며 공개 게시에 성공했다.

## Fish Audio 연결 (기본 비활성)

- `LONGFORM_TTS_PROVIDER=fish`는 본인 Voice ID, API 키, 사용 조건 확인 후에만 활성화한다. 기본값은 기존 edge 음성이다.
- Fish 모델 헤더는 `s2.1-pro-free`로 고정한다. 누락/오타 모델이 유료 모델로 처리될 수 있으므로 임의 모델 변경이나 유료 fallback 금지.
- 무료 요청 보관/모델 개선 사용, 상업 이용 조건은 사용자에게 설명하고 `LONGFORM_FISH_USE_ACK=true` 동의 후 사용한다. 음성 샘플을 임의로 업로드하거나 공개하지 않는다.
- Fish는 장면 오디오를 한 번만 만들고 같은 파일로 길이 검사와 렌더를 수행한다. 실패/응답 불명확 상태는 자동 재요청하지 않는다.

## 2026-10-01 시각 콘텐츠 제작

- 시각 장면 설계는 별도 LLM 호출 없이 검수된 대본과 sources.json을 사용한다. 기사 출처 카드와 설명 그래픽을 실제 촬영 영상처럼 표시하지 않는다.
- 원문 기사 이미지의 공개 여부는 재사용 허가가 아니다. 승인된 매체만 해시·권리·사건 출처·문장 앵커를 검사하여 배치한다. 과거 자료 사진은 촬영일과 자료 화면임을 명시한다.
- 최초 자료 라이브러리는 국회의사당 사진 한 장이다. 모든 사건의 실제 사진/영상 자동 수집을 완성했다고 주장하지 않는다. 추가 라이브러리는 실제 이미지와 이용 조건을 확인한 후만 확장한다.
- DoHyeon 글꼴에 뉴스 한자·기호 누락이 있었다. 넓은 한글 글꼴을 우선하고, 실제 MP4 디코딩 프레임을 보고 확인한다. 텍스트 테스트만으로 시각 품질을 단정하지 않는다.
- 디자인 검증은 기존 MP4 음성을 재사용하고 과거 자료 미리보기임을 표시한다. 검증용 오래된 영상을 게시하거나 새 API 생성을 반복하지 않는다.

## 자동 사건 자료 수집

- media_collect는 원문 JSON-LD/OG와 Commons를 검색하되 개별 이용 허가, 정확한 원문 연결, 촬영일, 대본 교집합을 모두 충족한 것만 자동 채택한다. OG/검색 순위/이름 일치만으로 승격하지 않는다.
- 자동 채택은 메타데이터 검사이며 얼굴/행위의 시각적 증명이 아니다. reviewed=true로 사람 검수를 위조하지 않는다. 실패·보류·검색 0건은 그래픽 대체가 정상이다.
- media-collection.json으로 원인을 먼저 보고, 같은 입력은 캐시한다. 하루 수집 예산 18요청/50MB, 자료당12MB, 이슈당2개. 제한을 풀거나 유료 도구로 우회하지 않는다.
- 9/23 기사 실제 수집 점검은 6요청, 채택0건이었다. 개별 자료 권리 정보가 없어 보류된 것이며 실제 사건 사진 삽입 성공으로 보고하면 안 된다.

## 해외 근거와 시각 자료 분리

- 국제 자료는 국내 이슈 선정 후 별도 피드에서 최근 원문을 추가한다. 언어 간 키워드 일치는 교차 확인 후보일 뿐 사실 확인 결과가 아니다. 공식 기관 입장과 해외 언론을 구분한다.
- Google News RSS는 발견 기록만 저장한다. 원문을 읽지 않은 검색 요약을 근거로 쓰거나 사진 허가로 간주하지 않는다. 유료 검색·번역 API는 추가하지 않는다.
- 기존 대본/95점 검수 호출에서 번역의 추정·부정·예정과 사건 동일성을 확인한다. 자료는 이슈당4,000자 범위에서 출처별 배분하고 추가 LLM 호출은 하지 않는다.
- 해외 사진/영상은 개별 사용 조건 외에도 양쪽 원문의 정확한 인용으로 뒷받침된 same_event 검수를 요구한다. 검수 누락/오류는 보류하며 reviewed=true로 사람 검수를 위조하지 않는다.

## 2026-10-06 연속 시각 편집

- illustrations/에는 이 채팅의 built-in image_gen으로 제작·시각 확인한 설명 그림 6종과 원문 프롬프트/해시가 있다. GitHub가 ChatGPT 이미지 생성을 호출한다고 설명하지 않는다. 일일 제작은 저장된 그림을 재사용하며 유료 이미지 API를 추가하지 않는다.
- 실제 사건 자료는 기존 권리·근거 검사를 유지한다. 설명 그림은 별도 illustration 필드에만 기록하고 AI 생성/실제 현장 아님 표시를 화면과 설명란에 넣는다. 실제 인물·사건을 합성 사진으로 대체하지 않는다.
- 대본 문장을 우선해 주제를 매칭하고 미지의 주제는 중립적인 자료 검토 그림으로 채운다. 출처·수치·요약 화면도 유지한다. 같은 그림의 구도 변화는 새 원본 이미지 수로 부풀려 보고하지 않는다.
- 약 6초 단위 확대·구도 변화는 렌더 단계에서만 적용한다. 컷 수를 늘리기 위해 TTS/LLM을 다시 호출하거나 음성 길이를 늘리지 않는다. 검증은 과거 음성 재사용 미리보기로 하고 이를 신규 뉴스로 게시하지 않는다.

## 설명 동영상의 제작 방식 구분

- 사용자는 제작에 크레딧을 더 쓰는 것은 허용했지만 별도 구독 구매를 승인한 것은 아니다. Weave 연결 성공은 유료 실행 권한을 의미하지 않는다. 비용 견적과 실행 가능 여부를 확인하기 전 생성 가능하다고 단정하지 않는다.
- motion.py는 GPT가 작성한 코드 기반 MP4 애니메이션이다. Sora/Veo 등 생성 모델로 만든 동영상이라고 설명하지 않는다. 실제 촬영·실제 경로를 나타내지 않는다는 표시를 유지한다.
- 공급망/물류 문장에만 supply-chain 모션을 삽입한다. 실제 자료가 채택되면 이를 덮어쓰지 않는다. 날짜·수치·출처 카드는 보존하며 알 수 없는 주제에 무관한 동영상을 넣지 않는다.
- 8초 무음 모션은 한 실행에서 한 번 렌더하고 재사용한다. 음성은 기존 장면 음성을 유지하며 생성 API를 추가 호출하지 않는다.

## 일반 설명의 연속 배경 영상 (version 5)

- 위 공급망 전용 규칙을 확장했다. 일반 설명은 외교·입법·경제·시민 생활·물류·자료 확인의 6개 모션 중 문장 우선으로 선택하며, 모호하면 중립 자료 확인 배경을 쓴다.
- 출처 카드·수치·검증된 실제 자료·요약 첫 화면은 배경보다 우선한다. 중요도는 임의 점수가 아니라 이 명시적 규칙으로 판단하며 visual_priority/selection_reason을 기록한다.
- 문장마다 재생을 0초로 되돌리지 않는다. 누적 오디오 시간의 8초 나머지로 루프를 시작하며 동일 배경의 움직임을 이어간다. 테마별 영상은 버전별로 실행당 한 번만 생성하고 재사용한다.
- GitHub에서는 코드 모션그래픽을 로컬 FFmpeg로 생성한다. 별도 영상 API·Weave·추가 결제 없이 작동하며 숏폼 경로를 수정하지 않는다.
