# Privacy Policy — political-shorts

Last updated: 2026-09-01

political-shorts is a personal command-line tool, run by its developer, that publishes short videos to the developer's own YouTube channel. It has no other users.

## Data it accesses

A Google OAuth token with the `https://www.googleapis.com/auth/youtube.upload` scope, used solely to upload videos to the developer's own YouTube channel.

## Data it stores

The OAuth access and refresh token, stored only on the developer's local computer. Nothing is stored on any server, and no data is shared with any third party.

## What it does not do

It does not collect, process, store, sell, or transfer data belonging to any other person.

## Data deletion

Revoke access at https://myaccount.google.com/permissions and delete the local token file to remove all stored data.
