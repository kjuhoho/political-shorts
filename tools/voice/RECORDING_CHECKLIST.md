# 내 목소리 녹음 체크리스트

목표: **내 목소리 녹음 → 학습 → 내 목소리로만 말하는 TTS**.
아래를 순서대로 따라가면 됩니다. 녹음은 **한 번만** 제대로 하면 이후 계속 씁니다.

---

## 0. 방식 정하기 (읽고 넘어가기)

| | 파인튜닝 (권장) | 밑바닥부터(from scratch) |
|---|---|---|
| 필요한 녹음 | **20~40분** | 3~10시간+ |
| 결과 음색 | **100% 내 목소리** (베이스 모델은 발음·억양 뼈대만 제공, 음색 기여 0) | 100% 내 목소리 |
| 품질(30분 기준) | 좋음 | 나쁨(데이터 부족) |
| Colab 시간 | 1~3시간 | 10시간+ |

"오직 내 음성만"이라는 목표는 **파인튜닝으로도 완전히 충족**됩니다 — 나오는 목소리는
당신 것만 들립니다. 노트북 `MODE` 를 `scratch` 로 바꾸면 밑바닥 학습도 되지만,
사람이 혼자 3시간을 녹음하는 건 비현실적이라 **파인튜닝을 권장**합니다.

---

## 1. 장비 · 소프트웨어

- [ ] 마이크: USB 콘덴서(예: 블루 예티, 오디오테크니카 AT2020USB) 또는 괜찮은 헤드셋.
      노트북 내장 마이크는 최후의 수단(품질 낮음).
- [ ] 팝필터(없으면 마이크에서 살짝 비켜 말하기).
- [ ] 녹음 프로그램: **Audacity**(무료) 권장. 스마트폰 녹음 앱도 가능(무손실 설정).
- [ ] 조용한 방, 딱딱한 벽 반사가 적은 곳(커튼·옷장·이불 근처가 울림이 덜함).

## 2. 녹음 환경

- [ ] 냉난방기·공기청정기·냉장고·PC 팬 **끄기**. 창문 닫기.
- [ ] 휴대폰 무음, 알림 끄기.
- [ ] 마이크와 입 거리 **15~20cm 고정** — 문장마다 거리가 달라지면 학습이 흔들립니다.
- [ ] 같은 자리, 같은 마이크, 같은 설정으로 **한 세션에 몰아서**. 나눠 녹음하면
      매번 톤·거리·소음이 달라져 품질이 떨어집니다.

## 3. 녹음 설정

- [ ] 포맷: **WAV**, **48000Hz** 또는 44100Hz, **모노**, 16 또는 24bit.
- [ ] 입력 레벨: 가장 큰 소리에서 피크가 **-6dB ~ -3dB**. 빨간불(클리핑) 절대 금지.
- [ ] 문장 앞뒤로 **0.5초 정도 정적**만 남기고 자르기(길게 남겨도 빌더가 정리함).

## 4. 무엇을 어떻게 말하나

- [ ] 대본: `tools/voice/enrollment_ko.txt` 의 50문장.
- [ ] **평소 쇼츠 내레이션 톤** 그대로. 성우처럼 과장하거나 뉴스처럼 딱딱하게 X.
      너무 또박또박 X → "말하듯이".
- [ ] 문장당 **한 파일**. 틀리면 그 문장만 다시.
- [ ] 페이스·목소리 크기·감정 톤을 문장 사이에 **일정하게** 유지.
- [ ] 숨소리·입 소리(쩝) 최소화. 문장 시작 전에 숨 미리 쉬기.
- [ ] (선택·강추) 50문장 다 하고 여유 있으면 **내가 실제로 쓴 쇼츠 대본**을 문장 단위로
      더 녹음(`51.wav`, `52.wav` …). 도메인 문장이 많을수록 결과가 좋아집니다.
      그 문장들은 `tools/voice/enrollment_ko.txt` 아래에 `51 문장...` 형식으로 추가.

## 5. 파일 이름 (중요)

- [ ] `enrollment_ko.txt` 의 **줄 번호와 파일명이 정확히 일치**해야 합니다.
      `01` 줄 → `01.wav`, `02` 줄 → `02.wav` … (`1.wav` 아님, 두 자리 `01.wav`).
- [ ] 전부 한 폴더에: 프로젝트 안 **`recordings\`** (없으면 만들기).

## 6. 프리플라이트 (전체 녹음 전에 1번)

- [ ] `01.wav` 하나만 녹음.
- [ ] 실행:
      ```powershell
      .\.venv\Scripts\python.exe -m political_shorts voice dataset --audio recordings\
      ```
- [ ] 콘솔에 `<clip>`(너무 큼) / `<low>`(너무 작음) 경고가 없어야 함. 있으면 레벨·거리
      조정 후 다시.
- [ ] `dataset\wav\01.wav` 를 들어봐서 잡음·울림이 거슬리지 않으면 OK → 나머지 녹음 시작.

## 7. 녹음 다 한 뒤

- [ ] 파일 개수 확인: `recordings\` 에 `01.wav` ~ `NN.wav` 빠짐없이.
- [ ] 데이터셋 만들고 zip:
      ```powershell
      .\.venv\Scripts\python.exe -m political_shorts voice dataset --audio recordings\ --zip
      ```
      → `dataset\` (metadata.csv + wav\) + `dataset.zip` 생성.
      총 길이가 **10분 미만이면 경고** — 최소 20분, 가능하면 30분+.
- [ ] `dataset.zip` 을 `tools\voice\finetune_piper.ipynb` 셀 안내대로 Colab 에 업로드.
- [ ] Colab(런타임=T4 GPU)에서 위→아래로 실행 → `myvoice.onnx` + `myvoice.onnx.json` 다운로드.
- [ ] 두 파일을 프로젝트 **`models\`** 에 저장.
- [ ] `.env`:
      ```ini
      TTS_PROVIDER=piper
      VOICE_PIPELINE=true
      PIPER_BIN=tools\voice\piper\piper.exe
      PIPER_MODEL=models\myvoice.onnx
      ```
- [ ] 점검 & 시청:
      ```powershell
      .\.venv\Scripts\python.exe -m political_shorts voice doctor
      .\.venv\Scripts\python.exe -m political_shorts voice preview "오늘의 정치 뉴스를 정리해 드리겠습니다" --all-roles
      ```

## 8. 흔한 실수 (피하기)

- 문장마다 마이크 거리가 달라짐 → 음량·음색 들쭉날쭉.
- 감정 없이 밋밋하게 읽음 → TTS 도 밋밋해짐. 실제 영상 톤으로.
- 방 울림(에코) → 학습이 그 울림까지 배움. 흡음되는 공간에서.
- 배경 험(냉장고·에어컨 저주파) → `<low>` 는 안 떠도 품질 갉아먹음. 다 끄기.
- 세션을 며칠에 나눔 → 톤·환경 드리프트. 하루에 몰아서.
- 파일명 `1.wav` / `sentence01.wav` → 빌더가 못 찾음. 반드시 `01.wav`.
