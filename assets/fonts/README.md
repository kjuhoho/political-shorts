# Bundled display fonts (all SIL Open Font License 1.1 — free for commercial use)

- **BlackHanSans-Regular.ttf** — heavy "issue channel" display face, used for the
  persistent thumbnail title.  https://fonts.google.com/specimen/Black+Han+Sans
- **DoHyeon-Regular.ttf** — bold rounded, used for the numbered section labels.
  https://fonts.google.com/specimen/Do+Hyeon
- **Jua-Regular.ttf** — friendly rounded, used for body captions.
  https://fonts.google.com/specimen/Jua

Swap any of these by editing FONT_TITLE / FONT_LABEL / FONT_BODY in .env.
